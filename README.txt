INDRAPROJECTS website (v8)

Open index.html in any modern browser. No build step or server is needed.

What is new in v8
- Advanced project tracker: Project or Internship type, start date, deadline, progress slider with a daily update and note, update history, "Needs update" and "Internships" filters.
- Notifications: bell with unread count, alerts for pending daily updates, deadlines (3 days, today, overdue) and internship start dates. Optional browser/phone alerts at a daily reminder time (works while the page is open).
- Enquiry form: choose Course, Workshop or Internship. Internship shows categories (Website Development, Digital Marketing, Poster Designing, UI/UX Design, Logo & Branding, Business Analytics). Pick how to contact us (WhatsApp, Facebook, Instagram, LinkedIn, Email, Phone); after submit the details page opens with that link first.
- Register is also in the menu and the home page ("Apply for internship").
- Floating background shapes now move away from the cursor and float back.
- To set real social pages, edit the SITE object in index.html (Facebook, Instagram, LinkedIn).

What is new in v7
- Welcome animation (about 2.8 seconds) with the full logo, then the site opens.
- New pink / violet / cool-blue colour scheme with an animated floating background (shapes rise from the bottom and fall from the top).
- Full logo is shown (header, home circle, welcome screen) - no circle crop.
- Phone layout fixed: the rotating "Dream Design Develop Deliver" circle now sits beside INDRA PROJECTS exactly like on a laptop; header and bottom bar fit in one row.
- New menu space under "Client login". Edit the <div class="subnav"> block in index.html to add Home, Category, Services and more.
- Register: the client portal now has Log in / Register tabs (direct link: index.html#register).

Look and feel (earlier)
- Rounded corners and soft shadows.

Navigation
- The home page is split into full-screen pages: Home, Services, Courses, Workshops, Process, Contact.
- Move between pages with the mouse wheel, swipe up/down or left/right, arrow keys, or the dots on the right.
- Bottom bar: Previous page and social links (left), Back to top (right). Each social link uses the platform's own logo.

Courses
- 11 courses are listed on the Courses page. Tapping one opens a short form first; after submitting, the details page opens with WhatsApp and email buttons.

Client login and project tracker
- Log in from "Client login". Demo: client@indraprojects.com / demo1234
- Projects, milestones and deadlines are stored in the browser only.

Before going live
- Replace the Instagram, LinkedIn and Facebook links with the company's real pages.
- Form submissions are only kept in the browser. Connect an email service (for example Formspree or EmailJS) or a backend such as Supabase to receive them.
- Passwords are hashed in the browser, which is not secure for real clients. Use a real auth backend.
